# Docker deployment

For the complete frontend + backend + MySQL stack, use the root `compose.yaml`
and follow [docs/DOCKER.md](../docs/DOCKER.md). Run commands from the repository
root with the generated `.env.docker` file.

The older `backend/docker-compose.yml` below remains a backend/MySQL-only setup.
It uses different Compose project volumes. Do not run both stacks on port 8080
at the same time or assume they share database data.

# Run the backend with Docker Compose

From this directory, create the local environment file and set private values:

```powershell
Copy-Item .env.example .env
```

Edit `.env`: change both database passwords and replace `JWT_SECRET` with a Base64
secret generated by `openssl rand -base64 32`. Do not commit `.env`.

To send verification and password-reset emails, set `MAIL_ENABLED=true` and provide
`SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_AUTH`, and
`SMTP_STARTTLS`. The defaults keep email delivery disabled for local development.
Login and email-request rate limits are configurable with the `RATE_LIMIT_*`
variables in `.env.example`; the current limiter is in-memory and applies per
backend process, so multi-instance deployments need a shared rate-limit store.

Start the API and MySQL:

```sh
docker compose -f docker-compose.yml up --build
```

The API listens on `http://localhost:8080`. Swagger UI is available at
`http://localhost:8080/swagger-ui/index.html`; the OpenAPI document is at
`http://localhost:8080/v3/api-docs`.

Persistent Docker volumes keep MySQL data and uploaded item images across restarts.

## Runtime profiles

Local development defaults to `dev` and imports `.env` from the backend working
folder. Set `SPRING_PROFILES_ACTIVE=prod` explicitly for production and inject the
required environment variables into the container. The prod profile does not
import `.env` inside Spring, disables SQL logging and validates the Flyway schema.
Compose may still use an env file to supply container variables. See
`docs/PROFILE_CONFIG.md` for variables, isolated tests and V1-to-V2 upgrade steps.
